# GetToolInsights

Calls `POST /apigateway/aidex/insights/tool`.

Use the SDK browser-token or local-account password configuration described in the root quick start.

```sh
export NEXTHINK_API=web
export NEXTHINK_REQUEST_FILE="$PWD/examples/nexthink/web_api/ai_tools/GetToolInsights/request.example.json"
export NEXTHINK_LANGUAGE=en # optional; en or ja
go run ./examples/nexthink/web_api/ai_tools/GetToolInsights
```
