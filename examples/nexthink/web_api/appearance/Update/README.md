# Update

See the [resource guide](../README.md) for authentication, behavior and validation limits.

Set `NEXTHINK_ASSET_NAME` if using an asset other than menu-logo. Set `NEXTHINK_IMAGE_FILE` to the intended replacement and `NEXTHINK_IMAGE_CONTENT_TYPE` to its MIME type (for example image/png).

```sh
go run ./examples/nexthink/web_api/appearance/Update
```
