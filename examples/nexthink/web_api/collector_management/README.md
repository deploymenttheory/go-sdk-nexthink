# Collector device query

Configure `NEXTHINK_API=web`, `NEXTHINK_INSTANCE`, `NEXTHINK_REGION` and browser authentication as described in the [web API examples](../README.md). Run commands from the repository root.

QueryDevices lists Collector update status with platform/version/group/target-version filters and a positive limit. Send explicit empty filter arrays to select all values. The populated lab result matched curl. Existing Collector configuration methods remain documented in the web API example index.
