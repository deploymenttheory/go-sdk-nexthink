# Dashboards.GetProductShellMenu

Set `NEXTHINK_API=web`, `NEXTHINK_WEB_AUTH=chrome`, `NEXTHINK_INSTANCE`, and `NEXTHINK_REGION` with an authenticated Chrome portal session.

The observed lab response is an empty items array; item payloads remain raw JSON because their schema has not been observed.

```sh
go run ./examples/nexthink/web_api/dashboards/GetProductShellMenu
```
