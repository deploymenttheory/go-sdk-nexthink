# ListFilterCollections

These read-only methods retrieve the inventory collections, default columns and filter metadata used by the monitor visual editor. NEXTHINK_URI is a data-model URI such as device/device.

Use the authentication and inputs in the [resource guide](../README.md).

Required context: `NEXTHINK_URI` (see the resource guide for meanings).

From the repository root:

```sh
go run ./examples/nexthink/web_api/visual_editor/ListFilterCollections
```
